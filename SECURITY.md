# Security

Report a vulnerability in any folder of this hub, or in how a vault installs from it, to **security@oneiron.dev**. Write in English or Japanese. Say which folder, which version in its frontmatter, and how to reproduce.

We reply from the same address. We do not run a bounty. We credit reporters in the fix commit unless they ask us not to.

What this hub never contains, and what a report should flag if it ever does: a secret, a key, a credential, a credential file, personal data, or a script that reaches the network without the folder saying so and why.

Removal requests from a vendor or a folder's author go to **legal@oneiron.dev**. Everything else about a folder goes to **contact@oneiron.dev**.
