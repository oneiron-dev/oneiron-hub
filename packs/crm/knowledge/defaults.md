# Defaults

Every number a skill in this pack uses, in one place. A default is a starting value. The vault's own receipts outrank it once they exist. Source classes: `engine` (the engine's shipped value), `practice` (operator practice at the date shown), `provider` (a provider's published rule; see `platform-facts.md`).
