# GMass

Checked 2026-10-21. One first-hand account, useful as counter-evidence.

## What the vendor wrote

GMass stopped its 80,000-account warm-up system on 2023-01-31. Its owner wrote that Google required it to stop or lose Gmail API access. GMass now recommends smaller targeted cohorts and a real ramp instead.

## Reading it

This is vendor testimony, not a public Google statement. It shows that "warm-up is mandatory" is not a provider rule. It does not show that every other pool is shut down or that every warm-up signal is detected. Other vendors still sell pools, and the sources hold no controlled trial either way: `../practice/warm-up.md`.

## Loop default

Pooled warm-up off. A real-traffic ramp.
