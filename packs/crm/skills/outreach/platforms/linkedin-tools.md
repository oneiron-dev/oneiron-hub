# LinkedIn automation tools

Checked 2026-10-21. In this pack nothing connects to a person's LinkedIn account: the agent drafts and a human clicks (`../channels/linkedin.md`). This page is for an owner who runs a tool on their own account and wants the exposure sized.

## LinkedIn's rule

The prohibited-software page quotes the user agreement, §8.2: no "bots or other unauthorized automated methods to access the Services, add or download contacts, send or redirect messages". It also bans scraping and bypassing access limits. Members using prohibited tools risk accounts being "restricted or shut down". Cloud execution, a country-matched IP, slow pacing and a paid subscription do not make unauthorised automation authorised. Repeated automated-activity suspensions can become permanent. The agreement also requires one real-name account and bans account transfer; buying an aged account is not a workaround.

## What the vendors say about themselves

| tool | its own position | reading |
|---|---|---|
| HeyReach | recommends 25 invitations a day, up to 40 configurable; acceptance above 20%; long working windows; no concurrent manual activity; product weekly cap 200 | its own doc acknowledges account-specific LinkedIn limits; its numbers do not override LinkedIn's rule |
| Expandi | cloud execution, a dedicated country-matched IP, gradual warm-up and random pacing; ranks itself high in its own "safest tools" comparison | a self-ranking, not an independent ban study |
| Dripify | described in a competitor's comparison as moderate-volume sequencing with safety features | not independently read; no safe ceiling asserted |
| Waalaxy | publishes automated invitation and message quotas; plans of 300 or 800 invitations a month; discusses 200 a week | selling an allowance is not evidence LinkedIn grants it |
| PhantomBuster, Linked Helper and similar | scrapers and sequencers | the same prohibition applies; running outside a browser extension changes nothing |

The sources give no defensible restriction probability. A vendor "safety" score is not that statistic.

## Loop default

Native and manual prospect research, saved lists and alerts, drafting help, human-reviewed messages. No sending or scraping tool on the owner's account.

## If you override

The exposure is account restriction, then shutdown, with no number to size it. Record the tool and its daily settings on the override line. The engine's own LinkedIn send stays a human click whatever tool the owner runs beside it.
